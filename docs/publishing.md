# Publicação

1. Escolha um nome disponível no npm e atualize `package.json`.
2. Rode `npm run check`.
3. Rode `npm pack --dry-run` e verifique exports ESM/CJS e tipos.
4. Autentique-se no npm e publique com `npm publish --access public`.
5. Versione usando SemVer e adicione changelog em cada release.

Não publique chaves em `.env`, exemplos ou testes.
